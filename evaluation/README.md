# MyoVoice Evaluation

This directory contains evaluation scripts, metrics, and experimental results for the MyoVoice silent-speech recognition system.

Planned tasks:
- Evaluate the model using held-out EMG samples.
- Measure word or phrase recognition performance.
- Record relevant metrics and experimental settings.
- Compare model predictions with reference labels.
- Document limitations and future improvements.

Evaluation results will be added after the model has been trained and tested. No performance claims will be made before experimental validation.
