# MyoVoice Dashboard

This directory contains the user interface for the MyoVoice silent-speech recognition system.

Planned features:
- Display the word or phrase predicted by the EMG-based machine-learning model.
- Present recognition results clearly to the user.
- Provide a control to play the predicted text as audible speech.
- Support future integration with live EMG input and model predictions.

The dashboard will be connected to the recognition model and audio-output module as these components are implemented and tested.
